# Trigger Words

> **Single Source of Truth**: This file (`trigger-words.md`)
> **Load when**: User uses trigger words

## Core Workflow

| Trigger | Action |
|---------|--------|
| `co` | Continue — resume most recent task with full context recovery |
| `?` or `what next` or `wn` | What Next — analyse state, surface priorities, recommends next step |
| `session` | Session Recovery — diagnose incomplete items after compaction, fix, verify |

## Self-Improvement

| Trigger | Action |
|---------|--------|
| `u` or `update` | Review session work, propose skill/context updates, apply approved changes |
| `improve` | Improve ANY component — skills, prompts, menus, config, triggers, docs |
| `flow` | Trace and analyse how tasks execute from request to completion |
| `smooth` | Identify and fix friction and rough edges in recent execution |

## Creative

| Trigger | Action |
|---------|--------|
| `bs` or `brainstorm` | Quick Think or structured design sessions for ideation |
| `vc` or `visual-companion` | Browser-based diagram generation (requires visual-companion skill) |
| `svg` or `diagram` | Publication-ready SVG diagrams (requires svg skill) |

## Operations

| Trigger | Action |
|---------|--------|
| `g` or `guardian` | System health menu — report, status, improvements |
| `cron` | View, edit, monitor scheduled tasks |
| `space` or `sp` | Disk space analysis and cleanup |

## Navigation

| Trigger | Action |
|---------|--------|
| `menu` | Central menu hub for all available commands and skills |
| `nx` or `next-explorer` | Redisplay recent session files as clickable links |

## Task Management

| Trigger | Action |
|---------|--------|
| `d` or `deferred` | Parked task management — review, resume, bump, archive |
